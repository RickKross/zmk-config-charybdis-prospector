### Overview

This is a ZMK configuration for the [Charybdis](https://github.com/Bastardkb/Charybdis) 3x6 keyboard with a trackball
module featuring the PMW3610 optical sensor, paired with a [Prospector](https://github.com/carrefinho/prospector)
dongle.

Compatible with [Keymap Editor](https://nickcoutsos.github.io/keymap-editor/)
